## Becoming a Contributor

Anatomy 3D welcomes open-source contributors! To contribute:
1. Fork the repository (`authrain-cloud-abdullahformuli/anatomy`)
2. Create your feature branch (`git checkout -b feature/organ-mesh-optimization`)
3. Commit your enhancements
4. Open a Pull Request
